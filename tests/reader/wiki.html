Layout engine

A layout engine is the part of a browser that turns markup and style sheets into positioned boxes, which it then paints to the screen.[1] Engines are large, long-lived projects, often maintained by several companies at once.

Most engines share a pipeline: parsing, style resolution, layout, painting and compositing, with incremental updates when the document changes, so that typing or scrolling stays smooth.[2]

History

[edit]

Early engines were written for a single browser, but over time, several became shared components, embedded in mail clients, help viewers and application frameworks, as well as browsers.

Forks are common: a project is copied, renamed, and then evolves on its own, sometimes diverging so far that the shared ancestry is visible only in old file names and comments.

Design

[edit]

Engines are tested against large conformance suites, and new features usually ship behind flags first, so that web developers can try them before they are enabled for everyone.
